Session 8: Operating Systems & Settings

When you switch on a computer, the first big programme that wakes up is not Word or Chrome. It is the operating system (OS for short). Today you will learn what it does, meet the main operating systems, take charge of the Settings, keep a computer healthy and rescue a frozen programme. The Hub's computers are yours to practise on, so you will do all of it for real.

1. Plain Talk: The Headteacher

Think of your school. Pupils do not walk straight into the staff room, take chalk from the store or move into any classroom they like. The headteacher decides who uses which classroom, when, and keeps order so everything runs smoothly. On a computer, the programmes (apps) are the pupils, the hardware (processor, memory, storage, printer) is the classrooms, staff and store, and the operating system is the headteacher.

Figure 8.0: Apps never go straight to the hardware. They ask the operating system, which shares out the hardware fairly.

2. The Headteacher's Five Big Jobs

1. Starts the computer and shows you the desktop.

2. Runs programmes and shares out the processor and memory.

3. Looks after files and folders (File Explorer is part of Windows).

4. Talks to devices: keyboard, printer, Wi-Fi, sound.

5. Keeps it safe: user accounts, passwords, updates and antivirus.

2. User Accounts: Who Is Signed In?

A user account is your own space on a computer: your desktop, your Documents folder and your settings. You sign in with a name and a password or PIN. There are two main kinds:

👤 STANDARD USER

Can use programmes, save files and change their own settings. Must ask an administrator before installing some apps or changing settings for everyone. This is the safest account for everyday work.

🔑 ADMINISTRATOR

The "headteacher's key". Can install anything, change any setting and manage other accounts. When Windows asks "Do you want to allow this app to make changes to your device?", it is asking for administrator permission. Only say Yes if you know exactly what it is.

To see which kind you are: Settings → Accounts → Your info. If it says Administrator under your name you are an administrator; if not, you are a standard user (it may look slightly different on Windows 10).

🔒 LOCK IT BEFORE YOU LEAVE: Windows + L
On a shared computer, going to the toilet without locking is like leaving your school bag open on the bench. Press Windows + L: the screen locks, everything stays open, and only you can unlock it with your PIN or password. Never tell anyone your password, and never use a real one in this workbook.

Screenshots: A Picture of Your Screen

Press Windows + Shift + S, then drag a box round what you want. The picture is copied, so you can paste it (Ctrl + V) into Paint or a document, or click the pop-up to open it in the Snipping Tool and save it. Windows + PrtScn saves the whole screen in Pictures → Screenshots. Screenshots are great for showing a helper an error message (Session 9).

Keeping a Computer Healthy
Session 8 • Page 4

1. Four Healthy Habits

🔄 1. INSTALL UPDATES

Updates fix mistakes and close holes that criminals use to break in. Settings → Windows Update → Check for updates. When it asks you to restart, save your work first, and never switch off during "Working on updates".

🛡️ 2. KEEP ANTIVIRUS ON

Windows comes with Windows Security, a free antivirus. Open Start, type Windows Security → Virus & threat protection. Green ticks mean you are protected. Quick scan checks for harmful programmes (called malware).

🔁 3. RESTART NOW AND THEN

A restart clears the worktable (Session 6) and finishes updates. If a PC has been on for days and feels slow, Start → Power → Restart often fixes it.

🧹 4. INSTALL CAREFULLY, REMOVE WHAT YOU DON'T USE

To uninstall: Settings → Apps → Installed apps → the ⋯ beside the app → Uninstall. Fewer apps means more free space and fewer things running.

2. Where Is It Safe to Get Apps?

Figure 8.2: The app traffic light. Only install from places you can trust.
🚨 "YOUR PC IS INFECTED! CALL THIS NUMBER NOW!"
A pop-up in a web page that flashes red, beeps and tells you to call a number or download a "cleaner" is a scam. Real Windows Security never asks you to phone anyone. Do not click anything inside it. Close the browser tab (or the whole browser with Task Manager), tell your mentor, and run a Quick scan if you are worried.
