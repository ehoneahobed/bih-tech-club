Session 22: Spreadsheets 3: Working with Data

In Sessions 19 and 20 you typed numbers, wrote formulas, used SUM, AVERAGE, MAX and MIN, and drew a chart. In Session 21 your class answered a survey. Now you have a sheet full of real answers, called data. Today you learn to ask it questions: Who has the longest journey? How many of us walk? What food wins? Then you will tell the class what you found, in one clear sentence and one clear chart.

2. Freeze the Header Row

When you scroll down a long sheet, row 1 disappears and you forget which column is which. Freezing pins it to the top. In Excel: View → Freeze Panes → Freeze Top Row. Scroll down: the header stays!

Google Sheets: View → Freeze → 1 row. LibreOffice Calc: View → Freeze Cells → Freeze First Row.

3. Sort Without Breaking the Rows

Sorting puts the rows in order: A to Z (or Z to A) for words, smallest to largest (or largest to smallest) for numbers. But sorting has one famous trap:

Figure 22.2: The classic sorting mistake. Sorting one column on its own mixes up everybody's answers.
1
Click one cell in the column you want to sort by, for example D5 (Minutes). Do not click the column letter.
2
Data → Sort Largest to Smallest (for words: Sort A to Z). Excel sorts the whole table and keeps row 1 at the top. If a Sort Warning box appears, choose Expand the selection.

Google Sheets: freeze row 1 first, then Data → Sort sheet → Z to A. LibreOffice: Data → Sort Descending. Made a mess? Ctrl + Z straight away!

Filter & Count: COUNTIF
Session 22 • Page 3

1. Filter: Show Only the Rows You Want

A filter hides the rows you don't want to see right now, like asking only JHS 2 to step forward. Nothing is deleted: clear the filter and every row comes back.

Figure 22.3: Filtering the Travel column in Excel (Google Sheets: Data → Create a filter, and Data → Remove filter to bring the rows back. LibreOffice: Data → AutoFilter).

2. COUNTIF: Count Only the Matching Cells

You met =SUM and =AVERAGE in Session 20. COUNTIF counts how many cells in a range match a rule. It has two parts inside the brackets, separated by a comma:

=COUNTIF(C2:C21, "Walk")
WHERE TO LOOK: the range

C2:C21 means "the Travel answers, C2 through to C21". Leave out row 1, the header.

WHAT TO COUNT: the rule

"Walk" in quotation marks for words, spelt exactly like the cells. For numbers: 5, or ">4" for "more than 4".

IF, Highlights, Charts & Findings

1. The IF Function: Let the Sheet Decide

IF checks a test for every row and writes one answer when the test is true and a different answer when it is false. Imagine a teacher marking a test: "If the score is 50 or more, write Pass; if not, write Try again."

=IF(B2>=50, "Pass", "Try again")
Figure 22.4: The three parts of IF: the test, the answer if true, the answer if false. Words go in "quotation marks".

2. Conditional Formatting: Make Important Cells Glow

Conditional formatting colours cells automatically when they match a rule, like a highlighter that reads. Select F2:F21 (screen hours) → Home → Conditional Formatting → Highlight Cells Rules → Greater Than → type 4 → OK. Every value over 4 turns light red, and the colour updates if a number changes. Google Sheets: Format → Conditional formatting. LibreOffice: Format → Conditional → Condition.

3. From Numbers to a Clear Finding

Make your chart from your small COUNTIF summary table (the labels and the counts), not from the 20 raw rows. Remember Session 20: select the labels and the numbers, give the chart a title that says what it shows, and leave out any total. Then write a finding: one sentence that states a fact from the data, with a number.

✔ GOOD FINDINGS

"Half of our class (10 of 20) walk to school."
"Every pupil who comes by trotro or bus takes 40 minutes or more."

✘ NOT FINDINGS

"Pupils love walking." (The data didn't ask that.)
"Trotros are bad." (An opinion, with no number.)
