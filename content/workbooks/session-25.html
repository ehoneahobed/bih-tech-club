Session 25: Keyboard Shortcuts & Working Faster

You already know a few secret key combinations: Ctrl + Z to undo, Ctrl + C and Ctrl + V to copy and paste, and Ctrl + B for bold. Today you will learn the 20 shortcuts that save the most time, race your classmates with them, and try to use a computer with no mouse at all. By the end you will work like a real office professional.

1. Plain Talk: The Short Path Through the Market

Imagine Kofi needs to buy tomatoes at Makola. The long way is to walk all round the outside of the market. His aunt, who sells there, knows a short path between the stalls and is there in one minute. Same place, much less walking.

A keyboard shortcut is a short path on the computer. With the mouse, copying a word means: move to the ribbon, find the Home tab, find the Copy button, click. With a shortcut, your fingers never leave the keyboard: one quick press and it is done.

Figure 25.1: The long way and the short path. A few seconds saved, a hundred times a day, adds up to a lot of time.

2. How to Press a Shortcut: Hold, Tap, Let Go

A shortcut written Ctrl + S does not mean "press both at exactly the same moment". It means:

1. HOLD

Press and hold down the first key (Ctrl, Alt, Shift or the Windows key). These are called modifier keys: they change what the next key does.

2. TAP

While still holding it, tap the letter key once, quickly. Do not hold the letter down, or it may repeat.

3. LET GO

Let go of both keys. For three-key shortcuts like Ctrl + Shift + T, hold the first two, then tap the third.

💡 USE TWO HANDS FOR BIG STRETCHES
Your typing fingers already know where every key is. For a shortcut like Ctrl + P, hold Ctrl with your left little finger and tap P with your right hand. No twisting your hand like a crab!

2. Moving and Selecting Text Without the Mouse

Arrow keys move the cursor one letter at a time. Add Ctrl and it jumps a whole word. Add Shift and it selects as it moves.

Ctrl + ← Ctrl + → jump one word.
Shift + ← Shift + → select as you move.

Windows, Browser & Screenshot Shortcuts

1. Driving Windows with the Windows Key

The Windows key (the four-square logo, between Ctrl and Alt) is a master key for the whole computer:

ShortcutWhat happens
Alt + TabSwitch windows: hold Alt, tap Tab to step, let go on the one you want.
Windows key + DShow the Desktop at once. Press again to bring your windows back.
Windows key + ← / →Snap the window to the left or right half. (↑ maximises, ↓ shrinks it.)
Windows key + EOpen File Explorer (you met this in Session 4).
Windows key + LLock the PC. Your work stays open, but nobody else can use it.
Figure 25.3: Snapping two windows side by side. Windows 11 may then offer your other windows to fill the empty half.

2. Browser Shortcuts (Chrome and Edge)

TABS

Ctrl + T opens a new Tab.
Ctrl + W closes the tab you are on.
Ctrl + Shift + T brings back the tab you closed by mistake. A life-saver!

ADDRESS & REFRESH

Ctrl + L jumps to the address bar and selects it, ready to type a new address or search (Session 11).
F5 refreshes (reloads) the page. In PowerPoint, F5 starts the slide show: same key, different job!

3. Screenshots: A Picture of Your Screen

📸 WINDOWS KEY + SHIFT + S

The screen goes dim and the Snipping Tool opens. Drag a box round the part you want. The picture is copied: press Ctrl + V to paste it into a document or email. Windows 11 may also save it in Pictures > Screenshots.

🖥️ PRTSC (PRINT SCREEN)

On some PCs it copies the whole screen, ready to paste. On newer Windows 11 PCs it opens the Snipping Tool instead, just like Windows key + Shift + S. Try it on your PC and see which!

⚠️ THINK BEFORE YOU SNAP OR CLOSE
A screenshot copies everything in the box, including names, messages and passwords: check it before you share it. Ctrl + W closes a tab at once, so a half-filled form may be lost. Leaving your PC? Press Windows key + L.

On a Mac?

Apple computers use the Command key (⌘ Cmd) where Windows uses Ctrl: Cmd + C, Cmd + V, Cmd + Z, Cmd + S, Cmd + T and so on. A few are different: Cmd + Tab switches apps, Cmd + Shift + 4 takes a screenshot of part of the screen, Option + ←/→ jumps a word and Option + Delete deletes a word. Chromebooks use Ctrl, like Windows.
