Session 4: Files, Folders & File Explorer

Imagine if your headteacher threw all the school’s examination papers, receipts, letters, and student records into one giant pile in the middle of the staff room floor. Finding one student's terminal report would take days! That is why offices use filing cabinets with labeled folders. Today, you will learn how your computer organizes its digital filing cabinet.

1. Plain Talk: What is a File vs. a Folder?

📄 A FILE (The Content)

A single finished piece of work that has been saved onto the computer. A file contains actual text, drawing strokes, or sound.

Real-world Analogy: A single sheet of paper or an exercise book with your homework written inside.

Examples: My_Story.txt, Flag.png

📁 A FOLDER (The Container)

An empty, labeled digital container used strictly to hold and organize files or other subfolders. A folder contains no text of its own.

Real-world Analogy: A yellow manila cardboard folder or ring binder kept on a shelf.

Example: Science_Homework_2026

Meeting File Explorer

1. What is File Explorer?

File Explorer is the program built into your computer that lets you look inside your storage drives, open folders, create new folders, and arrange your files. Think of it as walking into the school library or records room.

⚡ THE FASTEST WAY TO OPEN FILE EXPLORER
Look down at your keyboard. Hold down the Windows Key ⊞ with your left thumb, and tap the letter E once: [ Win + E ]. File Explorer will open instantly! You can also click the yellow folder icon on the bottom Taskbar.

2. Anatomy of the File Explorer Window

Figure 4.1: Anatomy of File Explorer. Always check the Address Bar to see where you are!

3. The Four Standard Personal Folders

  • Documents: The primary home for your school reports, essays, and notes.
  • Pictures: Where photos, diagrams, and drawings from Paint are stored.
  • Downloads: Where files from the internet automatically land.
  • Desktop: Shows the files and shortcuts sitting right on your wallpaper.
Creating & Naming Folders
Session 4 • Page 3

1. How to Create a Brand-New Folder

Follow these 3 simple steps to create a folder anywhere on your computer:

1
Right-Click on Empty Space: Inside File Explorer, move your pointer to an empty white space. Click the Right Mouse Button (or bottom-right corner of your laptop touchpad).
2
Choose "New" → "Folder": In the menu that appears, hover your pointer over New, then glide across and left-click on Folder.
3
Type the Name & Press Enter: A yellow folder appears with the words "New folder" highlighted in blue. Do not click! Immediately start typing your desired folder name on the keyboard, then tap the Enter key.

2. The BIH Golden File-Naming Standard

When sharing school computers, files named doc1 or essay get lost immediately. Always use this 3-part naming formula:

[Subject or Project] _ [Topic] _ [YourName]
❌ BAD File Name (Avoid!) ✅ EXCELLENT BIH File Name
asdfghjkl.txt (Nonsense typing) Science_Photosynthesis_AmaMensah.txt
kofi's *awesome* drawing!!!.png Art_GhanaFlag_KofiBoateng.png
homework.docx (Which subject? Which week?) English_Comprehension_Week4.docx

3. The Forbidden Characters (Illegal Symbols)

🚫 SYMBOLS COMPUTERS WILL REJECT
The computer uses certain punctuation marks for its own internal code commands. You can NEVER use these 9 characters in a file or folder name:
\   /   :   *   ?   "   <   >   |
If you try typing any of these, the computer will beep and show a warning message refusing to save the name!

Saving Your Work: "Save" vs. "Save As"
Session 4 • Page 4

1. What is the Difference?

"SAVE AS..." (Giving Birth to a File)

Use Save As when you are saving a file for the very first time. It forces you to make two critical decisions:

  • WHERE to put the file (which folder).
  • WHAT to name the file.
"SAVE" (Updating Your Work)

Use Save after the file already has a name. It updates the file on the drive with any new sentences or changes you made since the last save.

It does not ask where or what name—it overwrites the old version quietly in a split second!

2. Anatomy of the "Save As" Dialog Window

When you click File → Save As in any program, this window appears. Follow the numbered steps:

Figure 4.2: The 3-Step Save As Process: 1. Pick destination folder → 2. Type clean file name → 3. Click Save!

3. The 5-Minute Save Habit (Ctrl + S)

⚡ BEAT DUMSOR & ACCIDENTAL CLOSURES
Every 5 minutes while working, press: Ctrl + S. This takes half a second and ensures that if power cuts, your essay is safely saved on the drive!

2. Panic Button / Troubleshooting

🚨 I clicked "Save", but I don't know where my file went!
Don't worry, your file is not lost!
  1. Open File Explorer (Win + E).
  2. On the left pane, click Quick access or Home at the very top.
  3. Look under the Recent Files section. Your newly saved file will be at the very top of the list!
